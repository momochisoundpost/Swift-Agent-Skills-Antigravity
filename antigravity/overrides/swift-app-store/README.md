# App Store Toolkit (Community)

App Store publishing preparation skills covering user-facing changelogs, App Store Optimization (ASO), and App Review compliance checks.

> [!NOTE]
> This is an unofficial community port for Google Antigravity. All bundled skills remain MIT-licensed by their respective upstream authors (see `NOTICE.md`).

## Included Skills (3)

| Skill | Upstream Repository | Author |
| --- | --- | --- |
| `app-store-changelog` | [Dimillian/Skills](https://github.com/Dimillian/Skills) | [Thomas Ricouard](https://github.com/Dimillian) |
| `app-store-aso` | [TimBroddin/app-store-aso-skill](https://github.com/TimBroddin/app-store-aso-skill) | [Tim Broddin](https://github.com/TimBroddin) |

## Usage

Enable the plugin in Customizations before submitting a release to draft changelogs, refine metadata keywords, and run pre-submission App Review checks.
