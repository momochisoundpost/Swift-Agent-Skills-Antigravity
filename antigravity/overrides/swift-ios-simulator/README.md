# iOS Simulator (Community)

Semantic iOS Simulator navigation, UI interaction, accessibility auditing, build-and-run, and diagnostic scripts.

> [!NOTE]
> This is an unofficial community port for Google Antigravity. All bundled skills and scripts remain MIT-licensed by their upstream author (see `NOTICE.md`).

## Prerequisites

- **macOS** with **Xcode** and Xcode Command Line Tools (`xcrun simctl`)
- **Python 3.12+**
- **`idb`** (`idb-companion` + `fb-idb`) for UI hierarchy inspection and touch/text automation

## Usage

Enable the plugin in Customizations on macOS when building, testing, or debugging iOS apps in the Simulator.
