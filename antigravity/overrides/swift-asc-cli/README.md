# App Store Connect CLI (Community)

26 modular skills for automating App Store Connect workflows using the `asc` command-line tool.

> [!NOTE]
> This is an unofficial community port for Google Antigravity. All bundled skills remain MIT-licensed by their upstream author (see `NOTICE.md`).

## Prerequisites

- **`asc` CLI**: Install the App Store Connect CLI (`asc`) and configure your App Store Connect API credentials (`ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_PRIVATE_KEY_PATH` or `asc auth login`) before running commands.
