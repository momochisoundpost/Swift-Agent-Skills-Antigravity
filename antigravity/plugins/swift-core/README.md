# Swift Core (Community)

Core Apple-platform development skills covering SwiftUI, SwiftData, Swift Concurrency, Swift Testing, and the Swift API Design Guidelines.

> [!NOTE]
> This is an unofficial community port for Google Antigravity. All bundled skills remain MIT-licensed by their respective upstream authors (see `NOTICE.md`).

## Usage

Enable the plugin in Customizations. Skills load on demand when working with SwiftUI views, SwiftData persistence, async/await and actors, Swift Testing suites, or Swift API naming and conventions.
