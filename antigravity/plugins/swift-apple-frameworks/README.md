# Apple Frameworks for Swift (Community)

Focused skills for Apple system frameworks and persistence workflows: FormatStyle, App Intents, Background Execution, Observability, WidgetKit, Core Data, and SwiftData testing.

> [!NOTE]
> This is an unofficial community port for Google Antigravity. All bundled skills remain MIT-licensed by their respective upstream authors (see `NOTICE.md`).

Enable the plugin in Customizations to access framework-specific best practices for Siri/Shortcuts integration, background scheduling, MetricKit/OSLog instrumentation, WidgetKit timelines, Core Data stacks, and SwiftData test harnesses.
