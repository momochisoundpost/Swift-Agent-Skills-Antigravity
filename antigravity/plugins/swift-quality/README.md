# Swift Code Quality (Community)

Architecture decision guidance, Swift/Apple security hardening, and codebase auditing skills.

> [!NOTE]

## Usage

Enable the plugin in Customizations to evaluate app architecture trade-offs, verify Keychain and CryptoKit usage, and run structured iOS codebase audits.
